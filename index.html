Decentralized Governance [ 03 ]

Bao Dao

A gasless on-chain voting platform that lets DAO members participate in governance without paying transaction fees. Members sign votes off-chain using cryptographic signatures; a relayer network verifies and submits them on-chain, removing the cost barrier while preserving full on-chain transparency and tamper-proof results.

Decentralized Exchange [ 04 ]

Vex Dex

A peer-to-peer token exchange where trades settle directly between wallets with no intermediary holding funds. Users sign trade orders off-chain; the smart contract validates both signatures, checks slippage and expiration, and executes the swap atomically in a single transaction — ensuring neither party is exposed to custody risk.

NFT Marketplace

A full-featured NFT marketplace supporting English and Dutch auctions, with decentralized metadata stored on IPFS. The smart contracts handle escrowed bidding, automatic royalty distribution, and gas-optimized settlement — all secured with reentrancy guards to protect users during active auctions.

Token-Gated Minting [ 06 ]

ERC Minter

A token-gated NFT minting platform where access is enforced entirely on-chain. Instead of relying on front-end checks that can be bypassed, the smart contract verifies each caller's ERC-20 token balance directly during the mint transaction — only holders who meet the threshold can mint, with no workarounds possible.
